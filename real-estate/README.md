# املاک اصغر شیدری

وب‌سایت فارسی و راست‌چین برای نمایش آگهی‌های املاک با Supabase.

## اجزای آماده
- رابط واکنش‌گرا و فهرست آگهی‌های منتشرشده
- جست‌وجو بر اساس نوع معامله، شهر/محله و حداقل متراژ
- صفحه جزئیات ملک و تماس مستقیم با دفتر
- ورود مدیر با Supabase Auth
- ثبت آگهی و بارگذاری چند تصویر در Storage
- پایگاه داده و سیاست‌های دسترسی RLS

## راه‌اندازی مدیر اول
1. در Supabase بخش Authentication > Users یک کاربر با ایمیل مدیر بسازید یا دعوت کنید.
2. کاربر یک‌بار از طریق فرم ورود سایت وارد شود تا پروفایلش ساخته شود.
3. در SQL Editor پروژه این دستور را با ایمیل مدیر اجرا کنید:

```sql
update public.profiles
set role = 'admin'
where id = (
  select id from auth.users
  where lower(email) = lower('YOUR_ADMIN_EMAIL')
);
```

4. مدیر از سایت خارج و دوباره وارد شود.

**مهم:** ثبت‌نام عمومی برای مدیر وجود ندارد؛ نقش مدیر فقط از سمت پایگاه داده تعیین می‌شود. کلید service_role یا secret را هرگز در مرورگر یا مخزن GitHub قرار ندهید. کلید publishable موجود در فایل فرانت‌اند برای استفاده عمومی طراحی شده و دسترسی‌ها با RLS محدود شده‌اند.

## اجرای محلی
فایل `real-estate/index.html` را با مرورگر باز کنید. اتصال اینترنت برای دریافت Supabase JS و فونت لازم است.

## پایگاه داده
Migrationها در پروژه Supabase با نام `amlak-asghar-shidari` اعمال شده‌اند. جدول‌ها:
- `profiles`
- `properties`
- `property_images`
و باکت عمومی `property-images`.

## محدودیت نسخه فعلی
این نسخه اولیه برای نمایش و ثبت آگهی آماده شده است. قابلیت ویرایش/حذف آگهی‌های موجود، بازیابی رمز عبور، مدیریت گالری تصاویر قدیمی و پنل حرفه‌ای کاربران هنوز نیازمند توسعه تکمیلی است.

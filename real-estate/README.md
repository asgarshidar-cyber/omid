# املاک اصغر شیدری

وب‌سایت فارسی و راست‌چین برای نمایش آگهی‌های املاک با Supabase.

## قابلیت‌های نسخه فعلی
- رابط واکنش‌گرا و فهرست آگهی‌های منتشرشده
- جست‌وجو بر اساس نوع معامله، شهر/محله و حداقل متراژ
- صفحه جزئیات ملک و تماس مستقیم با دفتر
- ورود مدیر با Supabase Auth
- ثبت آگهی و بارگذاری چند تصویر در Storage
- پایگاه داده و سیاست‌های دسترسی RLS

## فعال‌سازی حساب مدیر
1. در داشبورد Supabase پروژه `amlak-asghar-shidari` به بخش Authentication > Users بروید.
2. یک کاربر با ایمیل `asgar.shidari@gmail.com` ایجاد یا دعوت کنید. برای حساب رمز عبور امن تنظیم کنید.
3. پس از ساخته‌شدن حساب، trigger پایگاه داده به‌صورت خودکار نقش این ایمیل را `admin` می‌کند.
4. از صفحه سایت با همان ایمیل و رمز عبور وارد شوید.

در حال حاضر هیچ کاربر با این ایمیل در احراز هویت پروژه وجود نداشت؛ بنابراین نمی‌توانم بدون دسترسی به صندوق ایمیل یا انتخاب رمز از طرف صاحب حساب، حساب ورود را به‌جای او تکمیل کنم. دعوت‌نامه یا تأیید ایمیل باید توسط صاحب ایمیل انجام شود.

**امنیت:** ثبت‌نام عمومی مدیر در سایت وجود ندارد. کلید service_role یا secret را هرگز در مرورگر یا مخزن GitHub قرار ندهید. کلید publishable موجود در فایل فرانت‌اند برای استفاده عمومی طراحی شده و دسترسی‌ها با RLS محدود شده‌اند.

## اجرای محلی
فایل `real-estate/index.html` را با مرورگر باز کنید. اتصال اینترنت برای دریافت Supabase JS و فونت لازم است.

## پایگاه داده
Migrationها در پروژه Supabase با نام `amlak-asghar-shidari` اعمال شده‌اند. جدول‌ها: `profiles`، `properties`، `property_images` و باکت عمومی `property-images`.

## موارد توسعه بعدی
نسخه فعلی ثبت و نمایش آگهی‌ها را دارد. ویرایش/حذف آگهی‌های موجود، بازیابی رمز عبور و مدیریت کامل گالری تصاویر قدیمی هنوز پیاده‌سازی نشده‌اند.

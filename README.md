# اپلیکیشن فروشگاه امید

نمونه اولیه اپلیکیشن اندروید فارسی و راست‌چین با سبد خرید و پرداخت در محل.

## امکانات نسخه اولیه
- نمایش فهرست محصولات نمونه
- افزودن و کاهش تعداد کالا در سبد خرید
- محاسبه مبلغ سبد
- فرم آزمایشی اطلاعات تحویل
- ساخت خودکار APK با GitHub Actions

## نکته مهم
در این مرحله محصولات صرفاً نمونه هستند و فرم سفارش هنوز به سرور یا پایگاه داده متصل نیست؛ بنابراین سفارش واقعی ثبت یا به مدیر ارسال نمی‌شود. در مرحله بعد باید API امن، پایگاه داده، ورود مشتری، پنل مدیریت و اعلان سفارش پیاده‌سازی شوند.

## دریافت APK
پس از اجرای workflow با نام Build Android APK در بخش Actions، فایل خروجی از قسمت Artifacts قابل دانلود خواهد بود.

شناسه برنامه: `ir.omidstore.app`
